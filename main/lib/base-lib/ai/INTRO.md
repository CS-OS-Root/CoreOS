# MLA-C Framework

This repository contains the `mla-c` framework's `base-lib`, a C++ framework designed for high-performance and cross-platform applications without standard C/C++ standard library dependencies.

## Module Overview

`base-lib` provides core runtime utilities including:
- Custom data types and containers (`mla_string_t`, `mla_array_list_t`, `mla_hash_map_t`).
- Reference-counted memory management (`mla_pointer_t`, `mla_malloc`).
- Virtual file system and I/O stream abstractions.
- Task scheduler and single-threaded event loops.
- Cross-platform networking, HTTP, and WebSocket servers/clients.
